## ✨ Features
* **Smart Search:** ค้นหาร้านกาแฟตามย่านหรือชื่อร้านที่ต้องการ
* **Shop Details:** แสดงข้อมูลร้าน เมนูแนะนำ และเวลาเปิด-ปิด อย่างครบถ้วน
* **Map Integration:** ดูตำแหน่งที่ตั้งร้านและนำทางผ่าน Google Maps ได้ทันที
* **UI/UX:** ดีไซน์หน้าตาแอปให้ใช้งานง่าย เน้นความสวยงามและรูปภาพที่ชัดเจน

## 🛠 Tech Stack
* **Frontend:** React Native Expo (TypeScript)
* **API:** Google Places API / Custom Coffee Database
* **Navigation:** Expo Router
* **Styling:** Custom Theme System
